NVIDIA GeForce RTX 4070 Windows 11 配置 CUDA 踩坑记录¶

解决方案见 github issue: https://github.com/ntnu-arl/aerial_gym_simulator/issues/1. 下面简述问题和解决方案.

RuntimeError: nvrtc: error: invalid value for --gpu-architecture (-arch) nvrtc compilation failed:
